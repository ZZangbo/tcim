# TCIM Global Watch

전통의학과 보완통합의학(TCIM)의 글로벌 정책, 근거, 채용 동향을 격주로 수집해 한국어로 요약합니다.

**웹앱** → https://zzangbo.github.io/tcim/

2주에 한 번 월요일 아침에 새 호가 올라갑니다. 개별 호는 `?issue=N` 으로 바로 열 수 있습니다(예: [제2호](https://zzangbo.github.io/tcim/?issue=2)). 웹앱의 구독 탭에서 메일 수신을 신청할 수 있고, 신청된 주소는 운영자 확인 후 승인됩니다.

공개 자료를 개인 연구 목적으로 수집하고 정리한 것입니다. 논문 항목의 출처는 PubMed이며 DOI를 병기합니다.

## 저장소 구조

- `index.html` — 웹앱 전체. 빌드 없음, GitHub Pages가 그대로 서빙
- `RUNBOOK.md` — 격주 수집과 발행 파이프라인의 원본 규칙
- `schema.sql` — Supabase 스키마와 RLS 참조본
- `CLAUDE.md` — 작업 맥락

구조와 손대는 순서는 `CLAUDE.md`를 먼저 읽으세요.
